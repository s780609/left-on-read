# 已讀不回（Left on Read）

直立玩的像素風交友軟體模擬，大人向。主角陳冠宇，25 歲，老家嘉義，北漂第 2 年的小工程師，只會失敗，這是笑點。

## 玩法

- **開場**：約 35 秒的影片，可跳過、可從選單重看。
- **一天**：分白天、晚上、深夜。平日要上班，下班後選去吃飯或回租屋處泡麵，深夜滑交友軟體 Swipy，每晚最多 10 張卡，滑完只能去睡覺。
- **領薪**：每月 5 號入帳 36,000，扣房租水電 12,500。沒有 game over。
- **配對**：右滑才可能配對，連續右滑機率會下降。女角由臉、身材、年齡（22～38 歲）和學經歷隨機組合。
- **聊天**：配對後白天可以偷偷回訊息，晚上回到家、滑完 Swipy 之後也能回，每個聊天每天推進一步。
- **失敗圖鑑**：27 種原創失敗劇情，集滿有畢業典禮。
- **瓢蟲結局**：約 5% 的卡片是個工（個人工作室），聊幾天後會被問要不要去。不去是一筆隱藏失敗；去了就是瓢蟲結局，這一局結束，內容不露骨，可從圖鑑重看。

進度和圖鑑存在 localStorage，可完全離線遊玩（PWA）。

## 專案結構

```
src/
├── app/                    # Next.js App Router，首頁就是遊戲
├── components/
│   ├── original/           # 遊戲畫面、localStorage 存檔；pixel/ 是女角與介面的 canvas 繪圖
│   └── ui/                 # Service Worker 註冊
└── lib/
    ├── left-on-read/       # 遊戲邏輯（日曆、配對機率、女角產生器、劇情、圖鑑、狀態機、存檔容錯，含測試）
    ├── audio/              # Web Audio 合成音效
    ├── rhythm/             # 開場旋律用的音高換算
    └── settings/           # 音量設定
public/left-on-read/        # 開場與遊戲內場景的插圖
assets/heroine/             # 真結局女角的素材，還沒用在遊戲裡，不會打包進 App
```

週末房間（`scene/weekend.jpg`）和吃飯（`scene/eatery.jpg`）是由其他圖片合成的暫代圖。
